# 边缘资产与弱防护面测试清单(单厂商深度挖掘)

适用:公益/专属 SRC 单目标企业深度测试。核心思路——**先记录企业全称 → 找全资产 → 优先打边缘资产**(防护最弱,最容易出越权/未授权/密码重置/信息泄露)。

## 1. 边缘资产优先级策略

按防护强度从弱到强排序,优先测前面:

1. **开发测试环境**:`dev.`/`test.`/`pre.`/`staging.`/`beta.`/`uat.` 前缀子域、测试端口、测试路径
2. **后台/管理面**:admin 后台、OA、CRM、VPN/网关、邮箱系统、网盘
3. **API/接口域**:`api.`/`sapi.`/`open.`/`m.`(移动端)、文件服务器
4. **历史/废弃资产**:备案历史域名、证书透明度里的老子域、旧版本系统
5. 核心资产(官网/商城)最后测

**找边缘资产的方法**:

- 子域爆破:字典前缀加 `dev test pre staging beta uat oa vpn mail api app m mobile wx open sso passport file img static admin manage` 等
- 证书透明度(crt.sh)、subfinder 被动源
- FOFA/Quake 按企业名/备案号反查、favicon hash 关联
- 搜索引擎备案查询(ICP 主体)找同主体其他域名
- 主站 JS 里引用到的兄弟域名(经常泄露 api/文件/办公系统域名)

**判定与记录**:存活探测(httpx)后,每个资产记录:域名、IP、端口、指纹、状态码、功能入口 → `01-recon/assets.md`。与用户确认范围后再测。

## 2. 开发测试环境(dev/pre)重点检查

dev/pre 环境典型问题:调试开着、鉴权缺失、数据未脱敏、弱口令测试账号。

- 直接访问后台路径:`/admin`、`/login`、`/api`、swagger/actuator(Java)、`/debug`、错误详情页
- 未授权接口:抓主站接口在 dev 环境重放(删 Cookie/token)
- 测试账号弱口令:admin/admin、test/test、123456(1~2 次尝试即止,不做爆破)
- 报错信息:提交单引号/异常参数看是否回显堆栈、数据库报错(dev 环境常开详细错误)
- 数据脱敏:dev 环境是否用了生产数据(注册/订单查询,用自己数据验证)
- 目录扫描:dev 环境通常没做隐藏,备份文件/源码包命中率高(`www.zip`、`.git/`、`web.config.bak`)

## 3. 小程序/APP 接口分析

流程:抓包拿到接口域名 → 接口域名纳入资产清单 → 按 Web 清单逐项测接口。

**抓包**:
- 手机+电脑同网段,手机代理指到 Burp/Charles;HTTPS 需装证书(安卓 7+ 需 root 或自编译 APP,苹果需描述文件)
- 或用模拟器(夜神/雷电)配置代理抓小程序请求

**小程序反编译**:
- PC 微信打开小程序 → 找 `.wxapkg` 包 → 解包工具(如 wxappUnpacker)提取 JS
- 重点 grep:接口路径、`appid`/`secret`/`key`/`token` 硬编码、内网地址、隐藏功能入口
- 找到接口后:未授权访问(不带 token 直接调)、越权(改 userId/orderId)、参数注入(单引号)、敏感信息返回

**APP**:
- 硬编码凭证、证书校验缺失(可抓 HTTPS)、越权接口、调试接口

注意:仅测试授权范围内企业的小程序/APP;不碰第三方(微信/支付宝)平台资产。

## 4. 密码重置漏洞完整手法

核心:**改请求参数,验证码/链接发到攻击者**。

1. **改手机号/邮箱**:抓找回密码请求,把 `phone=受害者` 改成 `phone=自己`,若验证码发给自己且能重置他人密码 → 任意用户密码重置(高危)。
2. **响应包回显验证码**:发送验证码请求,看响应 JSON/HTML 是否直接回显验证码。
3. **改状态码/返回值跳过**:`{"code":400}` 改 `{"code":200}`、`success=false` 改 `true`、删除 `verifyCode` 字段重放。
4. **重置 token 问题**:token 可预测(时间戳/递增/用户id拼接)、不过期、可重放、未绑定手机号。
5. **万能验证码/验证码不过期**:000000/123456/888888;同一验证码多次使用、旧验证码仍有效。
6. **验证码爆破**:无频率限制时 4~6 位码可爆破(先确认无锁定,报告注明)。

验证规范:只用**自己注册的账号**互相演示;不动真实用户;证明漏洞即止,不真正改他人密码。
