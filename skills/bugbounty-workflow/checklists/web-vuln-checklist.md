# Web 漏洞测试清单(补天/SRC 实战向)

使用方式:按功能模块逐项排查。发现可疑点 → 记入 `02-scan/candidates.md`(资产、位置、可疑行为、初步想法)。
通用提醒:全程限速;只用自己的测试账号;任何批量/破坏性验证都不做。

## 1. 认证与登录

**弱口令/默认口令**
- 怎么找:后台、设备、中间件管理页(admin/admin、admin/123456、常见厂商默认口令);判断是否存在验证码/锁定策略,能爆破才试。
- 验证:极小字典(5~10 个)证明即可,不跑大字典。

**验证码绕过**
- 怎么找:万能验证码、验证码不过期(同一验证码重放)、删除/置空验证码参数、响应包回显验证码、图形码可 OCR、短信码无频率限制。
- 验证:用自己账号演示绕过过程并截图。

**短信轰炸**
- 怎么找:同一手机号无频率限制、换号绕过限制、图形验证码复用多次、并发发送。
- 验证:只发 2~3 条证明即可,禁止真实轰炸。

**找回密码逻辑**
- 怎么找:验证码回显在响应、修改返回包状态码跳过校验、越权重置他人密码(改 userid/phone 参数)、重置 token 可预测/未失效。
- 验证:两个自己的账号互相演示,不动真实用户。

**登录凭证**
- 怎么找:token 弱加密/可预测、凭证未绑定设备、登录接口明文传输密码。

## 2. 越权(IDOR / 权限绕过)

**水平越权**
- 怎么找:改 userId/orderId/id 等参数访问他人数据;注册两个账号 A/B 对比响应差异。
- 常见位置:个人中心、订单、工单、收藏、API 接口(`/api/v1/user/{id}`、`/order?id=`)。

**垂直越权**
- 怎么找:普通用户 token 调管理接口;直接访问 /admin 路径;改 role/isAdmin 参数。
- 验证:账号 A 的请求把 id 换成 B → 返回 B 数据 → 截图;只确认可越权,不遍历、不下载。

## 3. 业务逻辑

- 支付:改金额、改数量、负数、0 元购、订单参数重放、支付状态篡改。
- 优惠券:并发领取、重复使用、叠加使用、越权使用他人券。
- 流程绕过:跳过步骤(step 参数)、直接访问结算/完成页。
- 条件竞争:同一优惠券并发下单、并发兑换。
- 验证:测试环境/小金额;金额篡改以"拦截提交"方式证明,不实际下单大额。

## 4. SQL 注入

- 找点:搜索、筛选、排序(order by)、分页、报错参数、数字型 id。
- 手法:报错注入(extractvalue/updatexml)、布尔盲注、时间盲注。
- payload 示例:
  - `' and 1=1-- -` / `' and 1=2-- -`(差异判断)
  - `' and if(1=1,sleep(5),0)-- -`(**仅执行一次**)
  - sqlmap 确认:`sqlmap -u "URL" --batch --random-agent --level 2 --technique=B`
- 验证:确认注入点与数据库类型即止;不 dump 数据、不跑 `--os-shell`。

## 5. XSS

- 反射型:搜索框、报错页回显、URL 参数回显。
- 存储型:留言、评论、昵称、资料页、地址栏(影响面大,定级更高)。
- DOM 型:location.hash、document.write/innerHTML sink。
- payload:`<script>alert(document.domain)</script>`、`<img src=x onerror=alert(1)>`;绕过:大小写、双写、编码、标签闭合。
- 验证:弹窗截图;存储型说明影响范围(可窃取他人 cookie → 中/高危)。

## 6. SSRF

- 找点:图片/URL 导入、远程加载、webhook、PDF 导出、代理功能、回调地址参数。
- 验证:dnslog.cn 生成域名填入 → 查看是否收到 DNS 记录(证明外带);127.0.0.1 探测仅证明连通。
- 注意:不探测/访问目标内网敏感服务,外带确认即止。

## 7. 文件上传

- 绕过:后缀大小写、双后缀(.php.jpg)、00 截断、改 Content-Type、图片马、解析漏洞。
- 验证:先传无害探针(纯文本 .txt);确认可传脚本后缀且被解析后立即删除。
- 注意:不传真实 webshell 长期驻留;上传即删,报告附证据截图。

## 8. 信息泄露

- 源码/备份:`.git/`、`.svn/`、`.bak`、`.swp`、`www.zip`、编辑器残留、phpinfo。
- 敏感接口:未授权 API(用户列表、内部接口)、swagger、actuator、debug 页面、目录遍历。
- JS 硬编码:key/secret/token/内网地址;配合 gau 收集的 JS 批量 grep。
- 验证:证明危害明确(如 .git 可还原源码);不下载整个源码库,不保存敏感数据。

## 9. 配置错误

- CORS:Origin 反射且携带凭证 → 跨域窃取数据;验证时检查 `Access-Control-Allow-Origin` 是否回显请求 Origin。
- 未授权:后台/接口无鉴权直接访问(配合目录扫描)。
- 默认页面:phpinfo、测试页、示例程序。
- 弱加密/明文传输:登录接口明文密码(HTTPS 下明文 → 低危)。

## 10. 移动端/小程序(目标含 APP 时)

- 抓包分析接口,复用本清单 Web 思路。
- 小程序:反编译找密钥、隐藏接口、未授权 API。
- APP:硬编码凭证、越权接口、证书校验缺失。

## 定级参考(以平台实际标准为准)

- **高危**:未授权访问核心数据、SQLi、任意文件上传、影响面大的存储 XSS、支付逻辑绕过、垂直越权。
- **中危**:水平越权(敏感数据)、反射 XSS、SSRF 外带确认、源码/密钥泄露。
- **低危**:轻微信息泄露、无实际影响的配置问题。
